# Mục lục ghi chú kỹ thuật

Mở note theo chức năng, sau đó chỉ đối chiếu các file nằm trên luồng cần sửa. Đề cương mô tả nghiệp vụ dự kiến. Các note ghi hiện trạng triển khai và chỉ rõ phần còn thiếu.

| Khi nhắc tới | Đọc trước |
| --- | --- |
| Kiến trúc, route, API, xác thực, thêm màn hình mới | [Note 1 · Kiến trúc và điểm vào](note1.md) |
| F2.1, năm học, ghi chú, năm hiện hành | [Note 2 · Quản lý năm học](note2.md) |
| F2.2, học kỳ I/II, trùng hoặc chồng ngày | [Note 3 · Quản lý học kỳ](note3.md) |
| F2.3, lớp học, mã lớp, tìm kiếm, lọc và phân trang | [Note 4 · Quản lý lớp học](note4.md) |
| Chạy app, MySQL, migration, seed, lỗi 404/500 | [Note 5 · Vận hành và dữ liệu mẫu](note5.md) |

Khi bổ sung nghiệp vụ, tạo `note6.md`, `note7.md` theo thứ tự và cập nhật mục lục. Mỗi note ghi điểm vào, luồng xử lý, hợp đồng API, bảng liên quan, quy tắc, ca kiểm tra và phần còn thiếu. Khi đổi hành vi hoặc tên file, cập nhật note tương ứng.

Tài liệu gốc gồm [đề cương](../requirements.md), [thiết kế cơ sở dữ liệu](../database.md) và [README dự án](../../README.md). Các note này được đối chiếu với mã nguồn hiện tại, chưa thay thế tài liệu cài đặt.
